# FFOOD

FFOOD là một mẫu website cửa hàng đồ ăn / nhà hàng tĩnh được xây dựng bằng HTML, CSS và JavaScript. Dự án trình bày giao diện trang chủ, trang cửa hàng, chi tiết sản phẩm, trang giới thiệu và trang liên hệ.

## Tổng quan

- Giao diện hiện đại, thân thiện và phù hợp với trải nghiệm người dùng trên cả desktop và thiết bị di động.
- Tập trung vào nội dung sản phẩm, thanh điều hướng trực quan và phần tương tác giỏ hàng/đăng nhập.
- Sử dụng Bootstrap và Font Awesome để tăng tốc phát triển layout và biểu tượng.

## Cấu trúc thư mục

- `FFOOD/`
  - `index.html` - Trang chủ
  - `shop.html` - Trang cửa hàng chính
  - `shop_detail.html` và `shop_detail1.html` ... `shop_detail8.html` - Trang chi tiết sản phẩm
  - `about.html` - Trang giới thiệu
  - `contact.html` - Trang liên hệ
  - `assets/`
    - `css/base.css` - Các quy tắc CSS cơ bản
    - `css/style.css` - Kiểu dáng giao diện chính
    - `img/` - Ảnh trang web
    - `js/main.js` - JavaScript xử lý tương tác và chức năng

## Công nghệ sử dụng

- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3
- Font Awesome

## Hướng dẫn sử dụng

1. Mở thư mục `FFOOD` trong trình duyệt web.
2. Hoặc mở trực tiếp file `FFOOD/index.html` bằng trình duyệt.
3. Duyệt các trang: `shop.html`, `about.html`, `contact.html`, và các file chi tiết sản phẩm.

## Tính năng chính

- Menu điều hướng dễ sử dụng
- Giao diện responsive cho di động và máy tính để bàn
- Trang chi tiết sản phẩm đầy đủ
- Hỗ trợ icon, thanh tìm kiếm, tài khoản và giỏ hàng

## Ghi chú

- Đây là một dự án frontend tĩnh, chưa tích hợp backend hoặc cơ sở dữ liệu.
- Có thể mở rộng bằng cách thêm chức năng mua hàng, đăng nhập thực tế hoặc kết nối API.

## Liên hệ

Nếu bạn muốn phát triển thêm dự án này, hãy mở rộng bằng các bước sau:
- Tích hợp backend với Node.js, PHP hoặc bất kỳ framework phù hợp
- Sử dụng thư viện frontend hiện đại như React, Vue hoặc Angular
- Thêm quản lý sản phẩm và tính năng đặt hàng
